# PR #7152 — 기여자 코멘트 초안

> **미게시 초안.** 아래는 로컬 보정을 완료한 현재 시점의 본문이다. 원격 push·CI·Approve는 아직 수행하지 않았다. 이미지는 로컬 검토용 상대 경로이며, 게시 전 asset을 포함한 원격 commit SHA에 고정한 절대 raw URL로 바꾼다. 현재 상태에서 “수정 반영 완료” 또는 “CI 통과 후 승인 완료”라고 게시하지 않는다.

메뉴·툴바 영어 표시 작업 감사합니다. 기존 DOM 구조와 명령 ID를 유지하면서 정적 문자열을 분리한 방향에 동의합니다. 마크업의 i18n 속성 396곳을 제외하면 이전 HTML과 동일하고, 참조 키 385개가 ko/en catalog에 모두 있는 것을 확인했습니다.

### 리뷰 결과와 메인터너 보정

영어 서식 도구 모음에서 두 가지 배치 결함을 재현했습니다. 변경 범위가 작고 기존 레이아웃 계약을 유지하는 보정이어서, 원 기여 커밋을 보존한 채 메인터너 보정 커밋 **`e917cffb9`**을 로컬에 준비했습니다.

1. **600px: 스타일 선택 상자와 `Font Set`이 6.5px 겹침**
   - 영어 격자는 496px로 넓어졌지만 부모는 476px여서 첫 칸이 줄었습니다. 스타일 선택 상자는 고정 88px로 남아 옆 칸을 침범했습니다.
   - 영어 부모 폭도 함께 늘리고, 선택 상자가 자신의 격자 칸 안에 들어가도록 제한했습니다. 보정 후 두 상자 사이에 정상적인 **4px 간격**이 생깁니다. 같은 원인으로 생기던 좁은 화면의 겹침도 함께 해소했습니다.

2. **808px·962px: 영어 필드에 추가한 20px가 반응형 전환에 반영되지 않음**
   - 영어 808px에서는 더보기 버튼 오른쪽 **10px**, 962px에서는 마지막 정렬 버튼 오른쪽 **11px**가 화면 밖으로 나갔습니다.
   - 영어의 한 줄 compact 전환을 **828px**, 정렬 명령 전체 표시를 **982px**로 조정했습니다. 한국어의 기존 808/962px 경계는 유지합니다.
   - overflow controller도 같은 경계를 사용하도록 맞춰 패널 표시와 키보드 포커스가 CSS와 어긋나지 않게 했습니다. 962px에서는 더보기를 통해 정렬 명령 6개를 모두 사용할 수 있습니다.

아래 비교는 실제 CSS viewport 기준입니다. **962px은 원본에서 정렬 버튼 전체를 펼치는 경계**이며, 한 줄 배치가 처음 시작하는 경계는 808px입니다.

- 새 회귀 검사가 원본 PR의 겹침·잘림을 실제로 실패로 검출하는 음성 대조도 완료했습니다.

`Format Painter`의 가로 중앙 정렬은 정상입니다. 한 줄/두 줄 라벨 사이의 아이콘 세로 차이는 기존 한국어 UI에도 있는 정렬 방식이므로 이번 번역 PR의 차단 결함에 포함하지 않았습니다.

**로컬 검토 판정은 “메인터너 보정 후 수용 가능”입니다.** 보정 commit의 원격 반영과 해당 최신 head CI 확인 후 최종 Approve를 진행하는 것이 적절합니다. 현재 초안은 원본 head에 대한 Approve 완료를 뜻하지 않습니다. #5852의 나머지 번역 단계는 계속 별도 진행 범위로 남깁니다.
